# OptiForge

Оптимизатор FPS для **Minecraft 1.16.5** (Fabric). Автоматически определяет железо ПК и установленные моды и подстраивает настройки игры под них — повышает FPS и убирает лаги (частицы, дроп энтити, сканирование чанков) на слабых компьютерах.

## Возможности
- Автоопределение железа (по частоте CPU из `/proc/cpuinfo`).
- Определение установленных модов (sodium, lithium, phosphor, OptiForge-совместимые и свои).
- Автонастройка: дальность прорисовки (viewDistance), частицы, графика, FOV.
- Оптимизация энтити/дропа/частиц/блоков (EntityOptimizer, ItemOptimizer, BlockEntityOptimizer, ParticleOptimizer).
- HUD с FPS и текущим профилем оптимизации.
- Экран настроек (клавиша **F6**).

## Сборка
Требуется: JDK 17, Gradle 7.6, Fabric Loom 0.12.56, yarn `1.16.5+build.10:v2`, fabric-api `0.42.0+1.16`.

```
gradle build --no-daemon
```

Готовый мод: `build/libs/optiforge-1.0.jar`.

## Установка
1. Установи **Fabric Loader** для 1.16.5 и **Fabric API** `0.42.0+1.16`.
2. Положи `optiforge-1.0.jar` в папку `mods/`.
3. Запусти игру, нажми **F6** для настроек.
